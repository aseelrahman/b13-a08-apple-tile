# Tessera

A tile website built with Next.js and HeroUI.

## Getting Started

Install dependencies:

```bash
npm install
```

Run the dev server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view it.

## Tech Stack

- Next.js
- HeroUI
